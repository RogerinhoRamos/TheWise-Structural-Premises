Como conectar seu MetaTrader 5 ao Sentinel

O Sentinel lê as informações enviadas pelo robô TheWise Portfolio Sentinel (TWS) instalado no seu MetaTrader 5 local. Para que o robô consiga transmitir os dados, siga o passo a passo abaixo:

  1. Abra o seu MetaTrader 5.
  2. No menu superior, vá em Ferramentas ➡️ Opções (ou pressione Ctrl + O).
  3. Selecione a aba "Experts Advisors" (ou Robôs).
  4. Marque a caixinha "Permitir WebRequest para as URLs listadas:".
  5. Clique em "Adicionar nova URL" e insira exatamente o endereço: http://127.0.0.1:5000
  6. Clique em OK.

💡 Pronto! O MT5 agora tem permissão para enviar os dados de balanço, ordens abertas e histórico em tempo real para este Dashboard.

Como as estatísticas são calculadas?

  • Lucro Líquido: Soma de todos os lucros fechados menos taxas de swap e comissão das corretoras.
  • Taxa de Acerto (Win Rate): (Operações Vencedoras / Total de Operações) × 100.
  • Fator de Lucro (Profit Factor): Divisão do somatório de todos os lucros pelo somatório de todos os prejuízos. Setups robustos devem apresentar um fator acima de 1.40.
  • Filtro de Profundidade: O Sentinel analisa a data de cada trade histórico. Se você selecionar "Últimos 30 Dias", os cálculos de gráficos e estatísticas ignorarão completamente todos os trades mais antigos, recalculando os números instantaneamente no navegador.
